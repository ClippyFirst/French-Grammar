# French-Grammar — генеральна матриця граматичного покриття

> Статус: benchmark для повноти довідника. Версія: 2026-09-25.
>
> Цільова аудиторія: **носії української мови, які вивчають французьку**. Формулювання «україномовні» у старих документах вважаємо неточним і поступово замінюємо на «носії української» / «для носіїв української мови».

## 1. Принцип повноти

Цей довідник не повинен копіювати шкільний підручник або енциклопедичну граматику без відбору. Повним вважається покриття, за якого користувач може знайти правило, форму, функцію, контраст із близькою французькою конструкцією, типові винятки та практичні приклади для всіх системних граматичних явищ сучасної стандартної французької, потрібних від початкового до просунутого рівня.

За основу береться принцип «від звука до тексту»: сучасні довідкові граматики французької охоплюють звук/орфографію, морфологію, синтаксис і вживання, а не лише таблиці відмінювання. Рівні CEFR можуть бути використані для навігації, але не повинні бути структурним обмеженням довідника.

- **DONE** — окрема реалізована сторінка вже є.

## 3. Що означає «для носія української»

У кожній темі, де українська система реально змінює спосіб засвоєння французької, потрібен окремий блок **«Для носія української»**. Він не має бути формальним перекладом правила.

Пріоритетні контрасти:
- французький граматичний рід + артикль ↔ український рід і відмінювання;
- французькі артиклі ↔ відсутність артиклів в українській;
- обов'язковий виражений підмет у французькій ↔ значно вільніше опущення підмета в українській;
- SVO і фіксованіші позиції компонентів ↔ відносно вільний порядок слів в українській;
- COD/COI та клитичні займенники ↔ українська відмінкова система;
- y/en ↔ відсутність прямого одно-до-одного відповідника;
- французькі прийменники ↔ відмінки + прийменники української;
- passé composé / imparfait ↔ українська видо-часова система;
- subjonctif / conditionnel ↔ відсутність повного морфологічного аналога;
- participe passé та його узгодження ↔ інша організація дієприкметникових форм;
- ne...pas та інші негативні конструкції ↔ українське заперечення;
- est-ce que / inversion ↔ українська система питального речення;
- relative pronouns ↔ українські відносні слова та відмінкові форми.

Важливо: не слід стверджувати, що «українці завжди роблять X». Потрібно формулювати як **ризик інтерференції / типову точку контрасту**, якщо це справді підтверджено джерелами або корпусом помилок.

## 4. Висновок щодо старої матриці на 204 теми

Стара матриця була корисною як стартовий backlog, але її не можна вважати остаточним стандартом повноти. Вона:
- змішує граматику, орфографію, вимову й соціолінгвістику;
- дублює частину тем;
- не має окремої системи сполучників;
- недооцінює інфінітивні/дієприкметникові конструкції;
- недостатньо деталізує c'est/il est, представлення, complement clauses, information structure;
- не відокремлює ядро сучасної стандартної французької від літературних і регіональних явищ;
- містить застаріле формулювання «спільний рід» для французької;
- не враховує достатньо сучасну живу французьку.

Тому **204 — не магічне число**. Для проєкту важлива повнота систем, а не досягнення конкретного лічильника сторінок.

## 5. Definition of Done для теми

Тема вважається DONE лише якщо:
1. правило сформульовано українською;
2. французька форма/структура наведена без помилок;
3. є приклади з природним українським перекладом;
