# Методологія редакції French Grammar v2

## Мета

Створити україномовний довідник французької граматики, який одночасно працює як:

1. швидкий довідник за конкретним запитом;
2. системний підручник для самостійного опрацювання;
3. контрастивний ресурс для україномовного учня;
4. довідник із сучасної стандартної та розмовної французької.

## Принципи

### 1. Значення перед формою

Кожна сторінка має відповідати не лише на питання «як утворюється?», а й на питання:

- що конструкція означає;
- у якому контексті її вибирає носій;
- чим вона відрізняється від найближчої альтернативи;
- як українськомовний учень може помилитися.

### 2. Не використовувати хибні універсальні правила

Не писати:

- passé composé = завершена дія;
- imparfait = тривала дія;
- subjonctif = сумнів;
- que = subjonctif;
- будь-яке слово-індикатор автоматично визначає час.

Натомість пояснювати прототипове значення, контекст і межі правила.

### 3. Контрастивна методика

Українська використовується там, де вона реально допомагає:

- французький présent ↔ український теперішній/майбутній контекст;
- французькі минулі часи ↔ український вид;
- французький subjonctif ↔ українські конструкції з щоб, би/б та інші засоби;
- французькі артиклі ↔ відсутність прямого артиклевого відповідника в українській;
- французький порядок займенників ↔ значно вільніший порядок в українській.

Не робити українську рамкою для кожної сторінки.

### 4. Form–Meaning–Use

Для кожної суттєвої конструкції:

**Form → Meaning → Use → Contrast → Exceptions → Errors**

### 5. Мінімальні пари

Використовувати мінімальні пари там, де зміна форми змінює інтерпретацію:

- Je dormais quand il est arrivé.
- Quand je suis arrivé, il a fermé la porte.

### 6. Реалістичні помилки

Помилка повинна мати пояснення:

- інтерференція української;
- буквальний переклад;
- аналогія з англійською/іспанською;
- неправильна позиція;
- неправильне керування;
- узгодження;
- орфографія.

Не вигадувати помилки заради обсягу.

### 7. Норма і жива мова

Для сучасних явищ розрізняти:

- стандартне письмо;
- нейтральне усне мовлення;
- неформальне мовлення;
- стилістично марковані форми.

Розмовну форму не називати «неправильною», якщо вона нормативно описується як розмовна.

### 8. Приклади

Переважно:

- короткі;
- природні;
- контекстні;
- з українським перекладом;
- з достатньою кількістю прикладів для центральних тем.

### 9. Термінологія

Канонічні терміни:

- sujet — підмет;
- verbe — дієслово;
- COD — прямий додаток;
- COI — непрямий додаток;
- déterminant — визначник;
- article — артикль;
- adjectif — прикметник;
- adverbe — прислівник;
- préposition — прийменник;
- pronom — займенник;
- temps — час;
- mode — спосіб;
- accord — узгодження.

## Архітектура сторінки

Для більшості великих тем:

1. Швидко
2. Формула / парадигма
3. Утворення
4. Значення
5. Вживання
6. Контраст із близькими конструкціями
7. Винятки
8. Типові помилки
9. Українська перспектива
10. Пов’язані теми

Не створювати порожніх секцій.

## Що змінено у v2

- Виправлено надмірно спрощене пояснення passé composé.
- Виправлено надмірно спрощене пояснення imparfait.
- Додано окремий системний контраст passé composé / imparfait.
- Виправлено хибне правило «subjonctif = сумнів».
- Додано правильний контраст j’espère que + indicatif.
- Додано пояснення subjonctif passé та ne explétif.
- Додано окремі сторінки для subject pronouns, adjective position, comparative/superlative, futur proche, plus-que-parfait, conditionnel passé, impératif, relative pronouns, si-clauses, indirect speech і passive.
- Розширено контрастивні пояснення для україномовних.
