# Французька граматика — Довідник для україномовних

Довідник з французької граматики, створений спеціально для україномовних студентів і вчителів.
Містить понад 200 тем — від основ (алфавіт, читання) до складних конструкцій (пасивний стан,
непряма мова, субхюнктив).

## Як запустити

### Вимоги
- Node.js 18+
- npm

### Встановлення та розробка

```bash
# 1. Встановити залежності
npm install

# 2. Запустити сервер розробки
npm run dev

# 3. Відкрити у браузері
http://localhost:4320
```

### Будівництво для продакшну

```bash
npm run build
# створює статичні файли у ./dist/
```

Після збірки файли знаходяться у `dist/` — їх можна розгорнути на будь-якому
статичному хостингу (Netlify, Vercel, GitHub Pages тощо).

### Пошук

Сайт використовує [Pagefind](https://pagefind.app) для повнотекстового пошуку
без серверних залежностей. Індексуються всі markdown-сторінки.

## Структура проєкту

```
src/
├── components/       # UI-компоненти (Breadcrumbs, TOC, RelatedTopics, Header, Footer)
├── content/
│   └── fr/           # Мовістовий контент (markdown файли з frontmatter)
├── data/
│   └── categories.mjs # Список категорій граматики (20 категорій)
├── layouts/
│   ├── Base.astro    # Базовий HTML-шаблон (head, body, тема)
│   └── MarkdownPage.astro # Макет сторінки граматичної теми (breadcrumbs, TOC, related)
├── lib/
│   └── pages.mjs     # Допоміжні функції для роботи з контентом
├── pages/
│   ├── index.astro   # Головна сторінка
│   ├── 404.astro     # Сторінка помилки 404
│   └── fr/
│       ├── index.astro                    # Огляд усіх категорій
│       ├── [category]/index.astro         # Сторінка категорії
│       └── [category]/[topic].astro       # Сторінка теми
public/
├── styles/global.css   # Глобальні стилі
├── js/main.js           # Мінімальний JS (мобільна навігація, тема)
├── favicon.svg
└── robots.txt
```

## Як додати нову тему

1. Створіть файл у `src/content/fr/` з іменем-слагом (наприклад `article-omission.md`).
2. Додайте frontmatter з полями: `title_uk`, `title_fr`, `description_uk`, `category`, `order`, `related`, `tags`.
3. Напишіть контент, починаби з `## Швидко` (заголовок `## Пов'язані теми` не потрібен —
   він створюється автоматично з поля `related`).

Приклад:

~~~markdown
---
title_uk: "Назва теми"
title_fr: "Le titre en français"
description_uk: "Короткий опис для пошуку та breadcrumbs."
category: nouns
order: 1
related:
  - fundamentals/alphabet
tags: [keywords, here]
---

## Швидко

Коротке пояснення 2–5 речень.

## Формула

Таблиця або формула.

## Утворення

Докладне пояснення.

## Використання

### 1. Використання 1

Пояснення. Приклади з перекладом.
~~~
