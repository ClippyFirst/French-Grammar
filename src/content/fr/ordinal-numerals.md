# Порядкові числівники

## Швидка відповідь

Порядкові числівники позначають місце предмета в послідовності: premier, deuxième, troisième тощо.

### 1. Основна модель

Найпродуктивніша модель: **числівникова основа + -ième**: *deux → deuxième, trois → troisième, quatre → quatrième*.

*le deuxième chapitre* — другий розділ;

*la troisième fois* — третій раз;

*le centième anniversaire* — сота річниця.

### 2. Особливі форми

**premier / première** — перший / перша.

Для *un* не вживають звичайного *unième* у нейтральному порядковому значенні.

*second / seconde* також можливе зі значенням «другий», особливо коли йдеться про два елементи: *la seconde partie*.

### 3. Узгодження

*Premier* узгоджується з іменником: *le premier jour, la première semaine*. Більшість числівників на **-ième** не мають окремої форми роду: *le deuxième jour, la deuxième semaine*.

### 4. Артикль

Порядковий прикметник часто входить до групи з означеним артиклем: *le premier chapitre, la quatrième page*. Але конкретний детермінатив визначається всією конструкцією.

### 5. Дати та назви

У датах французька має важливу особливість: перше число місяця — **le premier**, а інші дні — кількісні числівники: *le premier mai*, але *le deux mai, le vingt-deux mai*.

### 6. Не плутати кількість і порядок

*deux chapitres* — два розділи;

*le deuxième chapitre* — другий розділ.

Перша конструкція відповідає на **combien ?**, друга — на **lequel dans l'ordre ?**.

### Підсумок

Кількісний числівник рахує, порядковий визначає позицію. Для *premier/première* треба вивчити окрему форму; решта порядкових здебільшого твориться регулярно.

## Практичний алгоритм

1. Визнач, чи потрібна точна кількість, порядок, частка або часова характеристика.
2. Вибери відповідний тип числівникової конструкції.
3. Перевір прийменник: **à, en, pendant, depuis, dans, de** мають різні функції.
4. Перевір особливі форми (*premier, cent, vingt, mille, demi*).
5. У письмовому тексті перевір типографічний формат чисел відповідно до жанру.

## Пов'язані теми

Цю конструкцію варто розглядати разом із кількісними словами, датами, часом, дробами та узгодженням іменникової групи.
