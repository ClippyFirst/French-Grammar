# Verbalisation

§§MDEMPH0§§ — утворення дієслівної лексичної одиниці від іншої основи або перехід одиниці до дієслівного використання. Французька використовує суфіксацію, префіксацію та інші моделі для створення нових дієслів.

## Нові дієслова

Сучасна французька регулярно створює дієслова для технологій, медіа та нових практик. Проте формальна можливість утворення не гарантує широкої нормативної або частотної прийнятності.

§§MDEMPH0§§ вважати будь-яке дієслово з §§MDEMPH1§§ автоматично продуктивною моделлю.
