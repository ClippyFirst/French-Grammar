**Pour** виражає кілька різних відношень: адресата, мету, призначення, користь, напрямок у часі та інші залежності.

## 1. Адресат

*Ce cadeau est pour Marie.*

## 2. Мета

*Je travaille pour réussir.*

*un outil pour écrire* — інструмент для письма.

## 3. Призначення

*une salle pour les étudiants* — приміщення для студентів.

## 4. Тривалість

*Je pars pour trois jours.* — їду на три дні.

Це не те саме, що **pendant trois jours**, яке описує тривалість події.

## 5. Не плутати з par

*un livre écrit par Marie* — авторство/виконавець.

*un cadeau pour Marie* — адресат.

## Алгоритм

Визнач: адресат, мета, призначення чи тривалість. Потім перевір керування конкретної конструкції.

## Мінітест

*Ce cadeau est ___ toi.* → **pour**.

*Il étudie ___ réussir.* → **pour**.
