# C'est vs il est

Порівняйте **C'est un bon professeur** і **Il est un bon professeur**. Обидві форми можливі в певних контекстах, але вони не є взаємозамінними в усіх конструкціях.\n\n## Типова модель il/elle est\n\n**Il/elle est + adjectif** без артикля — звичайна предикація: **Elle est compétente.** Так само професію або функцію можна назвати без артикля: **Il est professeur.**\n\n## Типова модель c'est\n\n**C'est + groupe nominal** часто ідентифікує або представляє: **C'est mon professeur. C'est une bonne idée.** Артикль перед загальним іменником тут є частиною іменної групи.\n\n## Коли c'est коментує ситуацію\n\n**C'est intéressant**, **c'est dommage**, **c'est difficile** часто оцінюють факт, подію або попередній вислів: **Il a refusé. C'est dommage.**\n\nНатомість **Il est dommage de partir** належить до іншої, книжнішої конструкції з impersonnel **il**.\n\n## Перед іменником\n\nПорівняйте: **C'est un médecin** — «це лікар / це один із лікарів» як ідентифікація; **Il est médecin** — професійна характеристика суб'єкта.\n\n## Для україномовного учня\n\nНе зводьте різницю до «c'est = це, il est = він є». Спочатку визначте, чи конструкція представляє/ідентифікує іменну групу, чи безпосередньо предикує властивість або роль підметові.
