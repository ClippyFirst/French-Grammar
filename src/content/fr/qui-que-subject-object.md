## Швидка відповідь

Для питань про особу базове розрізнення:

- §§MDEMPH0§§ може бути підметом: §§MDEMPH1§§
- §§MDEMPH0§§ може бути COD: §§MDEMPH1§§
- §§MDEMPH0§§ питає про річ і типово є COD: §§MDEMPH1§§
- для підмета-неособи в конструкції §§MDEMPH0§§ використовується §§MDEMPH1§§: §§MDEMPH2§§

Отже, переклад «хто/що» сам по собі недостатній.

## 1. Qui як підмет

§§MDEMPH0§§  
§§MDEMPH0§§

Той, про кого питають, виконує дію. Тому §§MDEMPH0§§ — підмет.

## 2. Qui як COD

§§MDEMPH0§§  
§§MDEMPH0§§

Тут підмет уже виражений: §§MDEMPH1§§. §§MDEMPH0§§ є об'єктом дії.

Порівняй:

§§MDEMPH0§§ → хто приходить? → підмет.

§§MDEMPH0§§ → кого ти бачиш? → COD.

## 3. Que як COD

§§MDEMPH0§§  
§§MDEMPH0§§

§§MDEMPH0§§ стоїть перед дієсловом і запитує про прямий додаток.

## 4. Qu’est-ce qui

Для речі або ситуації як підмета:

§§MDEMPH0§§  
§§MDEMPH0§§

Після §§MDEMPH1§§ стоїть §§MDEMPH0§§, бо питальна група виконує функцію підмета.

## 5. Qu’est-ce que

Для речі як COD:

§§MDEMPH0§§

§§MDEMPH0§§ — підмет, §§MDEMPH1§§ — присудок, §§MDEMPH2§§ — питальна група додатка.

## 6. Чому український переклад не достатній

Українське «хто» майже завжди підказує особу, але французьке §§MDEMPH0§§ може бути і підметом, і додатком:

§§MDEMPH0§§  
§§MDEMPH0§§ — структура вже інша.

Тому спочатку встановлюй синтаксичну роль, а потім перекладай.

## Алгоритм

1. Визнач, про особу чи неособу питають.
2. Знайди підмет речення.
3. Якщо питальна група сама виконує дію → підмет.
4. Якщо підмет уже є → питальна група може бути COD.
5. Після прийменника: §§MDEMPH0§§ для особи, §§MDEMPH1§§ для неособи.
