# Тривалість

## Швидка відповідь

Тривалість відповідає на питання **combien de temps ?** і виражається часовими іменниками з кількісними словами або прийменниковими конструкціями.

### 1. Кількість часу

*trois heures* — три години;

*deux jours* — два дні;

*plusieurs semaines* — кілька тижнів.

### 2. Pendant

**pendant + durée** виражає тривалість дії:

*J'ai travaillé pendant trois heures.* — Я працював три години / протягом трьох годин.

*Elle est restée là pendant une semaine.* — Вона залишалася там тиждень.

### 3. Depuis

**depuis** позначає початок періоду, який триває до моменту відліку:

*J'habite ici depuis trois ans.* — Я живу тут уже три роки.

Конструкція не просто відповідає українському «протягом»: вона встановлює часову точку початку та зв'язок із теперішнім або іншим референтним моментом.

### 4. En

**en + durée** може виражати час, потрібний для завершення дії:

*Il a terminé le travail en deux heures.* — Він завершив роботу за дві години.

Порівняй:

*Il a travaillé pendant deux heures.* — Він працював протягом двох годин.

*Il a terminé en deux heures.* — Він завершив за дві години.

### 5. Dans

**dans + durée** позначає момент у майбутньому через певний інтервал:

*Je reviendrai dans deux jours.* — Я повернуся через два дні.

Це не те саме, що *pendant deux jours*.

### Підсумок

**pendant** = тривалість; **depuis** = від початку до референтного моменту; **en** = час, необхідний для завершення; **dans** = момент через певний інтервал.

## Практичний алгоритм

1. Визнач, чи потрібна точна кількість, порядок, частка або часова характеристика.
2. Вибери відповідний тип числівникової конструкції.
3. Перевір прийменник: **à, en, pendant, depuis, dans, de** мають різні функції.
4. Перевір особливі форми (*premier, cent, vingt, mille, demi*).
5. У письмовому тексті перевір типографічний формат чисел відповідно до жанру.

## Пов'язані теми

Цю конструкцію варто розглядати разом із кількісними словами, датами, часом, дробами та узгодженням іменникової групи.
