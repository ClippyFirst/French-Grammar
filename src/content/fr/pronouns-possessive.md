# Присвійні займенники (Les pronoms possessifs)

## 🇺🇦 Для українськомовних

Присвійні займенники у французькій мові вживаються для позначення **належності** чи **володіння** чим-небудь. На відміну від української, у французькій вони узгоджуються **не лише з власником, а й з рідом та числом речі, якою володіють**.

### 🔹 Присвійні займенники

| Власник | Рід речі, якою володіють | Однина | Множина |
|---------|----------------------------|--------|---------|
| 1-ша ос. (я) | Чоловічий | **le mien** | **les miens** |
| | Жіночий | **la mienne** | **les miennes** |
| 2-га ос. (ти) | Чоловічий | **le tien** | **les tiens** |
| | Жіночий | **la tienne** | **les tiennes** |
| 3-тя ос. (він/вона) | Чоловічий | **le sien** | **les siens** |
| | Жіночий | **la sienne** | **les siennes** |
| 1-ша ос. мн. (ми) | Чоловічий | **le nôtre** | **les nôtres** |
| | Жіночий | **la nôtre** | **les nôtres** |
| 2-га ос. мн. (ви) | Чоловічий | **le vôtre** | **les vôtres** |
| | Жіночий | **la vôtre** | **les vôtres** |
| 3-тя ос. мн. (вони) | Чоловічий | **le leur** | **les leurs** |
| | Жіночий | **la leur** | **les leurs** |

### 📌 Приклади вживання

- C'est **mon** livre. → Це **моя** книга.
  - C'est **le mien**. → Це **моя** (чол. рід).
  - C'est **la mienne**. → Це **моя** (жіночий рід).

- C'est **ton** stylo. → Це **твій** олівець.
  - C'est **le tien**. → Це **твій** (чол. рід).
  - C'est **la tienne**. → Це **твоя** (жіночий рід).

- C'est **son** chat. → Це **його/її** кіт.
  - C'est **le sien**. → Це **його/її** (чол. рід).
  - C'est **la sienne**. → Це **його/її** (жіночий рід).

### ⚠️ Важливі правила

1. **Узгодження з рідом і числом речі, якою володіють**
   - Ce sont **mes** livres. → Ce sont **les miens**. (чол. рід, множина)
   - Ce sont **mes** voitures. → Ce sont **les miennes**. (жіночий рід, множина)

2. **Перед іменником** вживаються присвійні **прикметники** (mon, ton, son, etc.)
   - **Mon** livre, **ton** stylo, **son** chat

3. **Замість іменника** вживаються присвійні **займенники** (le mien, la tienne, etc.)
   - J'ai un livre. **Le mien** est intéressant. → У мене є книга. **Мої** цікава.

### 🇫🇷 vs 🇺🇦 Порівняння з українською

| Французька | Українська | Примітки |
|------------|-----------|----------|
| le mien | мій | Чоловічий рід, однина |
| la mienne | моя | Жіночий рід, однина |
| les miens | мої | Чоловічий рід, множина |
| les miennes | мої | Жіночий рід, множина |

### 💡 Поради для українськомовних

1. **Пам'ятайте про подвійне узгодження** - з власником і з рідом/числом речі
2. **Mon/ton/son + іменник** - це присвійний прикметник
3. **Le mien/la tienne + дієслово** - це присвійний займенник
4. **У множині закінчення -s для чоловічого роду, -es для жіночого**

### 📚 Вправи для закріплення

1. Замініть присвійний прикметник + іменник на присвійний займенник:
   - C'est **mon** livre. → C'est **le mien**.
   - Ce sont **tes** voitures. → Ce sont **les tiennes**.
   - C'est **sa** maison. → C'est **la sienne**.
   - Ce sont **nos** amis. → Ce sont **les nôtres**.

2. Доповніть речення правильним присвійним займенником:
   - J'ai un stylo. ___ est bleu. (le mien)
   - Tu as une voiture. ___ est rouge. (la tienne)
   - Il a des livres. ___ sont intéressants. (les siens)
   - Nous avons une maison. ___ est grande. (la nôtre)

3. Перекладіть українською:
   - C'est le mien. → Це моє.
   - Ce sont les tiennes. → Це твої.
   - La sienne est belle. → Її (власність) гарна.
   - Les nôtres sont là. → Наші (речі) там.

### ❌ Типові помилки українськомовних

1. **Плутання присвійних прикметників і займенників**
   - ❌ C'est mon. → ✅ C'est le mien.
   - ❌ Ce sont mes. → ✅ Ce sont les miens/les miennes.

2. **Неправильне узгодження з рідом речі**
   - ❌ C'est la mien. (помилка - жіночий рід) → ✅ C'est la mienne.
   - ❌ Ce sont les miens voitures. → ✅ Ce sont les miennes.

3. **Забування про число**
   - ❌ C'est le mien livres. → ✅ Ce sont les miens.

### 🎯 Додаткові приклади

- **З одягом:**
  - Ce manteau est **le mien**. → Це пальто **моє**.
  - Ces robes sont **les siennes**. → Ці сукні **її**.

- **З речами:**
  - Ce livre est **le tien**. → Ця книга **твоя**.
  - Ces stylos sont **les vôtres**. → Ці ручки **ваші**.

- **З тваринами:**
  - Ce chat est **le sien**. → Цей кіт **його**.
  - Ces chiens sont **les leurs**. → Ці собаки **їхні**.

### 📝 Присвійні прикметники (для порівняння)

| Особа | Однина | Множина |
|-------|--------|---------|
| 1-ша (я) | mon/ma/mes | mes |
| 2-га (ти) | ton/ta/tes | tes |
| 3-тя (він/вона) | son/sa/ses | ses |
| 1-ша мн. (ми) | notre/nos | nos |
| 2-га мн. (ви) | votre/vos | vos |
| 3-тя мн. (вони) | leur/leurs | leurs |

**Приклади:**
- **Mon** livre, **ma** voiture, **mes** amis
- **Ton** stylo, **ta** maison, **tes** idées
- **Son** chat, **sa** sœur, **ses** parents
