# Рід назв професій і функцій

Назви професій, посад і функцій утворюють кілька моделей гендерного оформлення. Для багатьох назв існує жіноча форма, але спосіб її творення залежить від конкретної лексеми.

## 1. Морфологічні моделі

Порівняй:

- *un étudiant → une étudiante*;
- *un président → une présidente*;
- *un directeur → une directrice*;
- *un acteur → une actrice*;
- *un vendeur → une vendeuse*.

Ці приклади показують, що одного суфікса для всіх професій немає.

## 2. Незмінна форма

Деякі назви мають однакову форму:

*un ministre / une ministre*;  
*un journaliste / une journaliste*.

Тут граматичний рід визначають детермінативи та узгодження:

*une journaliste compétente*.

## 3. Посада й назва особи

Не змішуй граматичний рід назви професії з біологічною статтю в абстрактному висловленні. Важливо, чи іменник називає конкретну особу, чи функцію/посаду в певній конструкції.

## 4. Сучасне вживання

Форми професій можуть мати історичні, регіональні або інституційні відмінності. Якщо назва рідкісна, нормативний словник або стиль конкретної установи важливіший за аналогію.

## Український контраст

Українські моделі на *-ка, -иця, -иня* не можна переносити на французьку. Наприклад, *directeur → directrice* не є просто механічною заміною українського суфікса.

## Типові помилки

❌ *une directeur* → ✅ *une directrice*  
❌ *une journalistee* → ✅ *une journaliste*

## Алгоритм

1. Визнач лексему професії.
2. Перевір її жіночу форму.
3. Якщо форма спільна, змінюй детермінатив та узгодження.
4. Перевір регістр та інституційне вживання.

## Мінітест

*directeur* → **directrice**; *journaliste* → **journaliste**.
