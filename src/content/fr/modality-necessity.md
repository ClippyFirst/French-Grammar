# Модальність необхідності

## Швидка відповідь

Необхідність виражається через §§MDEMPH0§§, §§MDEMPH1§§, §§MDEMPH2§§ та інші конструкції.

## 1. Devoir

§§MDEMPH0§§ є основним особовим засобом необхідності:

§§MDEMPH0§§ — Я мушу піти.

§§MDEMPH0§§ — Ви повинні заповнити цю форму.

## 2. Falloir

§§MDEMPH0§§ — безособове дієслово:

§§MDEMPH0§§ — Треба працювати.

§§MDEMPH0§§ — Треба, щоб ти прийшов.

У конструкції §§MDEMPH0§§ підрядне речення має власний підмет.

## 3. Être nécessaire

Формальніше формулювання:

§§MDEMPH0§§ — Необхідно перевірити дані.

§§MDEMPH0§§ — Необхідно, щоб ви були присутні.

## 4. Не плутати devoir і falloir

§§MDEMPH0§§ — Ти маєш / мусиш піти.

§§MDEMPH0§§ — Треба піти.

Перше формулює необхідність щодо конкретного суб'єкта, друге — безособову необхідність.

## 5. Практичний вибір

Для особового обов'язку — §§MDEMPH0§§. Для загальної вимоги — §§MDEMPH1§§ або §§MDEMPH2§§.

## Підсумок

Необхідність має особову та безособову реалізацію; вибір конструкції залежить від того, чи названо носія необхідності.

## Практичний алгоритм

1. Визнач модальне значення: можливість, необхідність, бажання, припущення, обов'язок або дозвіл.
2. Встанови носія модальності.
3. Вибери особову, безособову або лексичну конструкцію.
4. Перевір часову перспективу та контекст.
5. Не перекладай модальне дієслово одним українським словом без перевірки значення.

## Пов'язані теми

Пов'язано з §§MDEMPH0§§, §§MDEMPH1§§, інфінітивними конструкціями, непрямою мовою та часовою перспективою.
