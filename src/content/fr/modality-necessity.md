# Модальність необхідності

## Швидка відповідь

Необхідність виражається через *devoir*, *falloir*, *être nécessaire* та інші конструкції.

## 1. Devoir

**devoir + infinitif** є основним особовим засобом необхідності:

*Je dois partir.* — Я мушу піти.

*Vous devez remplir ce formulaire.* — Ви повинні заповнити цю форму.

## 2. Falloir

**falloir** — безособове дієслово:

*Il faut travailler.* — Треба працювати.

*Il faut que tu viennes.* — Треба, щоб ти прийшов.

У конструкції **il faut que + subjonctif** підрядне речення має власний підмет.

## 3. Être nécessaire

Формальніше формулювання:

*Il est nécessaire de vérifier les données.* — Необхідно перевірити дані.

*Il est nécessaire que vous soyez présent.* — Необхідно, щоб ви були присутні.

## 4. Не плутати devoir і falloir

*Tu dois partir.* — Ти маєш / мусиш піти.

*Il faut partir.* — Треба піти.

Перше формулює необхідність щодо конкретного суб'єкта, друге — безособову необхідність.

## 5. Практичний вибір

Для особового обов'язку — *devoir*. Для загальної вимоги — *falloir* або *être nécessaire*.

## Підсумок

Необхідність має особову та безособову реалізацію; вибір конструкції залежить від того, чи названо носія необхідності.

## Практичний алгоритм

1. Визнач модальне значення: можливість, необхідність, бажання, припущення, обов'язок або дозвіл.
2. Встанови носія модальності.
3. Вибери особову, безособову або лексичну конструкцію.
4. Перевір часову перспективу та контекст.
5. Не перекладай модальне дієслово одним українським словом без перевірки значення.

## Пов'язані теми

Пов'язано з *conditionnel*, *subjonctif*, інфінітивними конструкціями, непрямою мовою та часовою перспективою.
