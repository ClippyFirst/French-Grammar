**Chez** найчастіше означає «у когось / у чиємусь домі» або «у середовищі певної особи чи групи».

## 1. У людини

*Je vais chez Paul.*

*Nous sommes chez nos amis.*

Ідеться не просто про фізичну адресу, а про місце, пов’язане з людиною.

## 2. Професія та заклад

*chez le médecin*, *chez le dentiste*, *chez le coiffeur* — у лікаря, стоматолога, перукаря/у відповідному закладі.

## 3. Група

*chez les jeunes*, *chez les enfants* — серед молоді, серед дітей.

Тут **chez** уже не означає буквально «у домі».

## 4. Присвійні займенники

*chez moi*, *chez toi*, *chez lui*, *chez elle*, *chez nous*, *chez vous*, *chez eux*.

## 5. Алгоритм

1. Чи місце пов’язане з людиною/групою?
2. Для людини або її дому → **chez + nom/pronom**.
3. Для професійного закладу → перевір усталену модель.
4. Для узагальненої групи → «серед/у середовищі».

## Мінітест

*Je vais ___ Marie.* → **chez**.

*Il travaille ___ les jeunes.* → **chez**.
