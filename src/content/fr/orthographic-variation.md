# Допустима орфографічна варіантність

Не кожна відмінність у французькому написанні є помилкою. Для точного довідника потрібно розрізняти **допустимий варіант**, **редакційну перевагу** та **помилкову форму**.

## Три різні статуси

Допустимий варіант — форма, яку нормативне джерело визнає або допускає.

Редакційна перевага — з кількох допустимих форм видання обирає одну для послідовності.

Помилка — форма, яка не відповідає відповідній нормі чи лексемі.

Не можна робити висновок про статус лише з того, що форма відрізняється від підручника.

## Регістр і джерело

Варіант може бути пов'язаний із редакційною традицією, реформою, історичним написанням або спеціальним словником. Потрібно встановити причину відмінності.

## Український контраст

Україномовний учень може очікувати одного «єдиного правильного написання». Французька орфографічна практика інколи вимагає знати статус кількох форм.

## Практичний алгоритм

1. Зафіксуй варіанти точно.
2. Перевір нормативне джерело.
3. Визнач статус кожного.
4. Для власного тексту вибери один послідовний стиль.
5. Не називай допустимий варіант помилкою.

## Мінітест

Чи є будь-яке написання, відмінне від шкільного підручника, помилковим?

Відповідь: ні. Спочатку треба перевірити нормативний статус форми.
