## Швидка відповідь

У французьких дієсловах зміна написання основи часто потрібна **не для зміни граматичного значення**, а для збереження очікуваної вимови.

Тому корисно розділяти:

- **морфологічну модель** — яку форму вимагає особа й час;
- **орфографічну адаптацію** — як написати основу, щоб зберегти потрібну вимову;
- **лексичну нерегулярність** — коли форму не можна надійно вивести з простої моделі.

## 1. -ger: збереження [ʒ]

У дієсловах на **-ger** перед закінченням *-ons* з'являється **e**, щоб зберегти вимову [ʒ]:

> *manger* → **nous mangeons**

Без *e* написання *mangons* не передавало б потрібної вимови.

Порівняйте:

> *je mange*  
> *nous mangeons*  
> *ils mangent*

Це не нова дієвідміна, а орфографічна адаптація.

## 2. -cer: збереження [s]

У дієсловах на **-cer** перед *a/o/u* може з'являтися **ç**:

> *commencer* → **nous commençons**

Мета — зберегти звук [s]. Без *ç* літера *c* перед *o* зазвичай передавала б іншу вимову.

Порівняйте:

> *je commence*  
> *nous commençons*  
> *ils commencent*

## 3. -yer: зміна y / i

Для частини дієслів на **-yer** можливе чергування:

> *payer* → **je paie / je paye**

Обидві форми трапляються в сучасному вжитку. Для конкретного дієслова та конкретного словника потрібно враховувати нормативно засвідчені варіанти.

Не перетворюйте це на абсолютне правило «кожне -yer обов'язково стає -ie».

## 4. -eler і -eter

У частині дієслів подвоєння приголосної чергується з іншими орфографічними моделями:

> *appeler* → **j'appelle**  
> *jeter* → **je jette**

Але інші дієслова цієї формальної групи мають **è**:

> *acheter* → **j'achète**  
> *geler* → **je gèle**

Тому за самим закінченням **-eler/-eter** не можна завжди передбачити конкретну модель. Її треба вчити разом із дієсловом.

## 5. Зв'язок із наголосами

Чергування **é / è / e** може бути пов'язане з вимовою та орфографічною нормою:

> *préférer* → **je préfère**

Такі зміни не слід пояснювати як «інший час». Це все ще présent; змінюється написання основи.

## 6. Навіщо потрібні ці зміни

Для україномовного учня корисно бачити логіку:

**закінчення форми → позиція основи → вимова → орфографічна адаптація**

Наприклад:

> *manger* → *nous mangeons*  
> **-ons** створює позицію, де *g* потребує *e* для збереження [ʒ].

## 7. Не всі зміни однакові

| Тип | Приклад | Функція |
|---|---|---|
| *-ger* → *-geons* | *manger → mangeons* | збереження [ʒ] |
| *-cer* → *-çons* | *commencer → commençons* | збереження [s] |
| *-yer* → *-ie/-y* | *payer → paie/paye* | модель основи / варіантність |
| *-eler* → *-elle-* | *appeler → appelle* | орфографічна модель |
| *-eter* → *-ette-* | *jeter → jette* | орфографічна модель |
| *e → è* | *acheter → achète* | орфографічно-фонологічна адаптація |

## Українсько-французький контраст

Український учень може сприйняти зміну літери як зміну «кореня» або як окрему неправильну форму. У французькій частина таких змін системна й передбачувана в межах певного дієслівного класу.

Тому корисніше вчити:

> **manger — nous mangeons**  
> **commencer — nous commençons**  
> **appeler — j'appelle**

як пару **інфінітив + ключова чергована форма**, а не запам'ятовувати кожну форму ізольовано.

## Практична перевірка

Якщо ви бачите нове дієслово:

1. визначте його клас;
2. подивіться на основу;
3. визначте, чи виникає особлива фонетична позиція;
4. перевірте орфографічну модель;
5. для *-eler/-eter/-yer* не виводьте форму без словникової перевірки, якщо модель вам невідома.

## Куди далі

- **Групи дієслів** — класифікація дієслів і межі регулярних моделей.
- **Présent** — форми, у яких ці чергування найчастіше помітні.
- **Impératif** — деякі ті самі орфографічні моделі з'являються в наказовому способі.
