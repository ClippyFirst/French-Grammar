# Прийменники з назвами міст

Для назв міст базовою моделлю є §§MDEMPH0§§ для напрямку або місця та §§MDEMPH1§§ для походження.

## 1. Місто як місце або пункт призначення

> §§MDEMPH0§§
> §§MDEMPH0§§
> §§MDEMPH0§§

Тут §§MDEMPH0§§ не перекладається одним українським прийменником у всіх випадках: воно може відповідати «до», «в», «у», «на» залежно від конструкції.

## 2. Походження

Для походження використовується §§MDEMPH0§§:

> §§MDEMPH0§§
> §§MDEMPH0§§

Перед голосним:

> §§MDEMPH0§§

## 3. Не плутайте місто і країну

Порівняйте:

> §§MDEMPH0§§ — у Парижі / до Парижа
> §§MDEMPH0§§ — у Франції / до Франції

Для міста базова модель — §§MDEMPH0§§, тоді як для багатьох країн — §§MDEMPH1§§.

## 4. Назви районів та інших географічних об'єктів

Не кожна географічна назва поводиться як назва міста. Якщо назва позначає інший тип об'єкта, прийменник визначається відповідною моделлю:

> §§MDEMPH0§§, §§MDEMPH1§§, §§MDEMPH2§§.

Тому спочатку треба встановити, що саме називає іменник.

## 5. Міста з артиклем

Деякі власні назви міст мають артикль. У таких випадках прийменникова форма визначається всією назвою:

> §§MDEMPH0§§ → §§MDEMPH1§§.
> §§MDEMPH0§§ → §§MDEMPH1§§.

Отже, не слід автоматично додавати §§MDEMPH0§§ перед будь-якою географічною назвою.

## Алгоритм

1. Визначте тип географічної назви.
2. Якщо це звичайна назва міста — перевірте §§MDEMPH0§§.
3. Якщо назва має артикль — перевірте контрактовану форму.
4. Для регіонів, країн, островів та гір використовуйте їхні власні моделі.

## Мінітест

§§MDEMPH0§§ → §§MDEMPH1§§.
§§MDEMPH0§§ → §§MDEMPH1§§.
§§MDEMPH0§§ → §§MDEMPH1§§.
