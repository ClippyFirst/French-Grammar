# Прийменники з назвами міст

Для назв міст базовою моделлю є **à** для напрямку або місця та **de** для походження.

## 1. Місто як місце або пункт призначення

> **Je vais à Paris.**
> **J'habite à Lyon.**
> **Nous sommes à Marseille.**

Тут **à** не перекладається одним українським прийменником у всіх випадках: воно може відповідати «до», «в», «у», «на» залежно від конструкції.

## 2. Походження

Для походження використовується **de**:

> **Je viens de Paris.**
> **Elle revient de Lyon.**

Перед голосним:

> **Je viens d'Avignon.**

## 3. Не плутайте місто і країну

Порівняйте:

> **à Paris** — у Парижі / до Парижа
> **en France** — у Франції / до Франції

Для міста базова модель — **à**, тоді як для багатьох країн — **en / au / aux**.

## 4. Назви районів та інших географічних об'єктів

Не кожна географічна назва поводиться як назва міста. Якщо назва позначає інший тип об'єкта, прийменник визначається відповідною моделлю:

> **en Bretagne**, **dans les Alpes**, **sur une île**.

Тому спочатку треба встановити, що саме називає іменник.

## 5. Міста з артиклем

Деякі власні назви міст мають артикль. У таких випадках прийменникова форма визначається всією назвою:

> **Le Havre** → **au Havre**.
> **Le Mans** → **au Mans**.

Отже, не слід автоматично додавати **à** перед будь-якою географічною назвою.

## Алгоритм

1. Визначте тип географічної назви.
2. Якщо це звичайна назва міста — перевірте **à / de**.
3. Якщо назва має артикль — перевірте контрактовану форму.
4. Для регіонів, країн, островів та гір використовуйте їхні власні моделі.

## Мінітест

**Je vais ___ Paris.** → **à Paris**.
**Je viens ___ Toulouse.** → **de Toulouse**.
**Il habite ___ Havre.** → **au Havre**.
