# Comment

**Comment** питає про спосіб або характер дії:

> **Comment vas-tu ?**
> **Comment fais-tu cela ?**
> **Comment fonctionne cette machine ?**

У відповідь часто описується спосіб:

> **Je le fais rapidement.**

## Comment + adjectif

У конструкціях на кшталт:

> **Comment est-il ?**

питання може стосуватися характеристики людини або предмета.

Не плутайте **comment** з **combien**: перше питає про спосіб/характеристику, друге — про кількість або міру.
