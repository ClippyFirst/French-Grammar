# Особисті займенники (Les pronoms personnels)

## 🇺🇦 Для українськомовних

Особисті займенники у французькій мові вживаються для позначення осіб, які беруть участь у діалозі або розмові. Вони можуть бути **підметом** (суб'єктом) або **додатком** (об'єктом) речення.

### 🔹 Особисті займенники як підмет (Pronoms personnels sujets)

| Особа | Однина | Множина |
|-------|--------|---------|
| 1-ша | **je** (я) | **nous** (ми) |
| 2-га | **tu** (ти) | **vous** (ви) |
| 3-тя | **il** (він), **elle** (вона), **on** (вони/ми) | **ils** (вони чол.), **elles** (вони жін.) |

#### 📌 Приклади вживання

- **Je** suis étudiant. → **Я** студент.
- **Tu** es beau. → **Ти** гарний.
- **Il** travaille. → **Він** працює.
- **Elle** chante. → **Вона** співає.
- **On** va au cinéma. → **Ми** йдемо в кіно. (неформально)
- **Nous** sommes amis. → **Ми** друзі.
- **Vous** êtes sympa. → **Ви** симпатичні.
- **Ils** étudient. → **Вони** (чоловіки) вчаться.
- **Elles** dansent. → **Вони** (жінки) танцюють.

### 🔹 Особисті займенники як додаток (Pronoms personnels objets)

#### Прямий додаток (COD - Complément d'Objet Direct)

| Особа | Форма |
|-------|-------|
| 1-ша | **me** (мене), **nous** (нас) |
| 2-га | **te** (тебе), **vous** (вас) |
| 3-тя | **le** (його), **la** (її), **les** (їх) |

**Приклади:**
- Il **me** voit. → Він **мене** бачить.
- Je **te** vois. → Я **тебе** бачу.
- Elle **le** connaît. → Вона **його** знає.
- Nous **les** aimons. → Ми **їх** любимо.

#### Непрямий додаток (COI - Complément d'Objet Indirect)

| Особа | Форма |
|-------|-------|
| 1-ша | **me** (мені), **nous** (нам) |
| 2-га | **te** (тобі), **vous** (вам) |
| 3-тя | **lui** (йому/їй), **leur** (їм) |

**Приклади:**
- Il **me** parle. → Він **мені** розповідає.
- Je **te** téléphone. → Я **тобі** телефоную.
- Elle **lui** écrit. → Вона **йому** пише.
- Nous **leur** donnons un cadeau. → Ми **їм** даруємо подарунок.

### ⚠️ Важливі особливості

1. **On** може означати:
   - "ми" (неформально): On va au parc. → Ми йдемо в парк.
   - "вони" (невизначено): On dit que... → Кажуть, що...
   - "люди" (загально): On doit respecter les règles. → Люди повинні поважати правила.

2. **Vous** може бути:
   - Формальною формою "ти": Vous êtes beau. → Ви гарний. (до старшої особи)
   - "Ви" у множині: Vous êtes beaux. → Ви гарні.

3. **Le/la/les** як додатки:
   - Замінюють іменники: J'ai un livre. Je **le** lis. → У мене є книга. Я **її** читаю.

4. **Lui/leur** вживаються з непрямими додатками:
   - Je parle à Marie. → Je **lui** parle. → Я розмовляю з Марією. → Я **їй** розмовляю.

### 🇫🇷 vs 🇺🇦 Порівняння з українською

| Французька | Українська | Примітки |
|------------|-----------|----------|
| je | я | |
| tu | ти | Неформально |
| il | він | |
| elle | вона | |
| on | ми/вони/люди | Контекст залежить від ситуації |
| nous | ми | |
| vous | ви | Формально або множина |
| ils | вони | Чоловічий рід |
| elles | вони | Жіночий рід |

### 💡 Поради для українськомовних

1. **Пам'ятайте про рід** - у французькій важливо розрізняти il/elle/ils/elles
2. **On = ми (неформально)** - часто вживається у розмовній мові замість nous
3. **Vous = ти (формально) або ви (множина)** - контекст важливий
4. **Прямі додатки (me, te, le, la, les)** - відповідають на питання "кого? що?"
5. **Непрямі додатки (me, te, lui, leur)** - відповідають на питання "кому? для кого?"

### 📚 Вправи для закріплення

1. Замініть підкреслені слова займенниками:
   - J'aime **Marie**. → Je **l'**aime.
   - Nous voyons **les enfants**. → Nous **les** voyons.
   - Il parle à **moi**. → Il **me** parle.
   - Elle écrit à **nous**. → Elle **nous** écrit.

2. Доповніть речення правильним займенником:
   - ___ suis heureux. (je)
   - ___ es intelligent. (tu)
   - ___ travaille beaucoup. (il)
   - ___ sommes amis. (nous)
   - ___ êtes sympathiques. (vous)

3. Перекладіть українською:
   - Je te vois. → Я тебе бачу.
   - Il nous écoute. → Він нас слухає.
   - Elle lui téléphone. → Вона йому телефонує.
   - Nous leur donnons un livre. → Ми їм даємо книгу.

### ❌ Типові помилки українськомовних

1. **Плутання il/elle** через незнання роду іменника
   - ❌ La table, il est belle. → ✅ La table, elle est belle.

2. **Неправильне вживання on**
   - ❌ On sommes amis. → ✅ Nous sommes amis. (on не вживається з sommes)

3. **Забування про займенники-додатки**
   - ❌ J'aime Marie. Je vois Marie. → ✅ J'aime Marie. Je **la** vois.

4. **Плутання lui/leur**
   - ❌ Je parle à eux, je lui parle. → ✅ Je parle à eux, je **leur** parle.

### 🎯 Додаткові приклади

- **З дієсловами:**
  - Je **m'**appelle Pierre. (Я зватися П'єр) - рефлексивний займенник
  - Tu **te** laves. (Ти миєшся)
  - Il **se** rasé. (Він голиться)

- **З прийменниками:**
  - avec **moi** (зі мною)
  - sans **toi** (без тебе)
  - pour **lui** (для нього)
  - chez **eux** (у них)
