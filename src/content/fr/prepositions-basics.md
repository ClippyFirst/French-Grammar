# Французькі прийменники

## Швидка відповідь

Французький прийменник не має одного стабільного українського відповідника. Його вибір визначають значення, тип конструкції та §§MDEMPH0§§ конкретного слова.

Тому §§MDEMPH0§§, §§MDEMPH1§§, §§MDEMPH2§§.

## Основні системи

| Прийменник | Типові функції | Приклад |
|---|---|---|
| §§MDEMPH0§§ | адресат, місце, напрямок, час | §§MDEMPH1§§, §§MDEMPH2§§, §§MDEMPH3§§ |
| §§MDEMPH0§§ | походження, належність, тема, керування | §§MDEMPH1§§, §§MDEMPH2§§, §§MDEMPH3§§ |
| §§MDEMPH0§§ | країни, транспорт, стан, тривалість | §§MDEMPH1§§, §§MDEMPH2§§, §§MDEMPH3§§, §§MDEMPH4§§ |
| §§MDEMPH0§§ | внутрішній простір, майбутній момент | §§MDEMPH1§§, §§MDEMPH2§§ |
| §§MDEMPH0§§ | поверхня | §§MDEMPH1§§ |
| §§MDEMPH0§§ | нижнє положення | §§MDEMPH1§§ |
| §§MDEMPH0§§ | місце, пов'язане з особою/професіоналом | §§MDEMPH1§§, §§MDEMPH2§§ |
| §§MDEMPH0§§ | мета, адресат, призначення | §§MDEMPH1§§ |
| §§MDEMPH0§§ | засіб, шлях, агенс | §§MDEMPH1§§, §§MDEMPH2§§ |
| §§MDEMPH0§§ | супровід, засіб у певних конструкціях | §§MDEMPH1§§ |
| §§MDEMPH0§§ | відсутність | §§MDEMPH1§§ |

Це карта системи, а не таблиця «переклад → прийменник».

## Керування

Порівняйте:

- §§MDEMPH0§§

- §§MDEMPH0§§
- §§MDEMPH0§§ — без прийменника
- §§MDEMPH0§§

Французький прийменник часто є частиною лексичної моделі слова. Український відмінок не дозволяє механічно передбачити цю модель.

## Час

Порівняйте:

> §§MDEMPH0§§ — Я виконаю це за дві години.

> §§MDEMPH0§§ — Я закінчу через дві години.

Також:

> §§MDEMPH0§§

> §§MDEMPH0§§

Українське «за / через / протягом» може відповідати різним французьким конструкціям.

## Практичний алгоритм

1. Визначте керувальне слово.
2. З'ясуйте його французьку конструкцію.
3. Перевірте, чи потрібен прийменник.
4. Якщо це §§MDEMPH0§§, перевірте злиття.
5. Лише після цього співвіднесіть конструкцію з українським перекладом.
