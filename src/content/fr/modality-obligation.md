# Модальність обов'язку

## Швидка відповідь

Обов'язок може виражатися особовим *devoir*, безособовим *falloir*, нормативними конструкціями та імперативом.

## 1. Особовий обов'язок

**devoir + infinitif**:

*Vous devez présenter une pièce d'identité.* — Ви повинні пред'явити документ.

*Je dois finir ce travail aujourd'hui.* — Я мушу закінчити цю роботу сьогодні.

Носій обов'язку є граматичним підметом.

## 2. Безособова вимога

**il faut + infinitif**:

*Il faut partir maintenant.* — Треба вирушати зараз.

**il faut que + subjonctif**:

*Il faut que vous partiez maintenant.* — Треба, щоб ви вирушили зараз.

## 3. Нормативний обов'язок

Для правил і приписів можливі:

*Il est obligatoire de porter un casque.* — Обов'язково носити шолом.

*Vous êtes tenu de respecter le règlement.* — Ви зобов'язані дотримуватися правил.

Вибір залежить від жанру й рівня формальності.

## 4. Obligation та nécessité

*Il faut remplir le formulaire.* — Форму треба заповнити.

*Il est nécessaire de remplir le formulaire.* — Необхідно заповнити форму.

Обидві конструкції виражають необхідність, але друга часто звучить формальніше.

## Підсумок

Розрізняй **devoir** для особового носія обов'язку, **falloir** для безособової вимоги та формальні нормативні конструкції.

## Практичний алгоритм

1. Визнач модальне значення: можливість, необхідність, бажання, припущення, обов'язок або дозвіл.
2. Встанови носія модальності.
3. Вибери особову, безособову або лексичну конструкцію.
4. Перевір часову перспективу та контекст.
5. Не перекладай модальне дієслово одним українським словом без перевірки значення.

## Пов'язані теми

Пов'язано з *conditionnel*, *subjonctif*, інфінітивними конструкціями, непрямою мовою та часовою перспективою.
