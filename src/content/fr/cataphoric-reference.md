# Катафорична референція

**Катафорична референція** виникає, коли форма спочатку з'являється без повністю вираженого референта, а його ідентифікація подається пізніше: *Quand il est arrivé, Paul a téléphoné.* — *il* передує *Paul*.

## Анафора проти катафори

Анафора відсилає назад: *Paul est arrivé. Il a téléphoné.* Катафора — вперед: *Quand il est arrivé, Paul a téléphoné.*

## Функція

Катафорична організація часто використовується для побудови залежної частини перед головним повідомленням. Вона не означає, що займенник не має референта; референт просто встановлюється пізніше.

## Типові помилки

Не трактуйте порядок слів як автоматичну заборону катафори. Треба перевіряти, чи дозволяє конструкція однозначно встановити референцію.

**Алгоритм:** знайдіть займенник → перевірте попередній контекст → якщо референта ще немає, перевірте наступний контекст → перевірте узгодження.
