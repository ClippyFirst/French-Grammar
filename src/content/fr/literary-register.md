# Літературний регістр

Літературний регістр — стилістично марковане використання французької, характерне передусім для художніх текстів.

## Синтаксис

Можливі інверсія, еліпсис, незвичний порядок компонентів, складні періоди та стилістично маркована лексика:

> *Vint alors le moment tant attendu.*

Це розповідна інверсія, не питання.

## Не плутати зі старою французькою

Сучасний літературний текст може використовувати сучасну граматику, але створювати особливий ефект через синтаксис, ритм або лексику. Рідкісна форма не автоматично є архаїчною.

## Для читання

Учневі важливо вміти відновити базову структуру:

*Vint alors le moment…* → *Le moment… vint alors.*

Для активного повсякденного мовлення таку інверсію не потрібно механічно копіювати.

## Український контраст

Українська теж має стилістично мотивований порядок слів, але французький базовий порядок жорсткіший. Літературність не означає необмежену перестановку.

**Типова помилка:** сприймати кожен незвичний порядок як довільний.

**Алгоритм:** знайдіть предикат → аргументи → відновіть базовий порядок → визначте стилістичне переміщення.
