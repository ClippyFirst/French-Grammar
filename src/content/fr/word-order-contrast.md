# Французький порядок слів ↔ українська відносна свобода порядку

Французький порядок слів сильніше пов'язаний із синтаксичною структурою, ніж український. Українська відмінкова система дозволяє переставляти компоненти, зберігаючи їхні граматичні ролі, тоді як французька частіше використовує позицію слова для розрізнення підмета й додатка.

## Базова модель

> *Paul voit Marie.*

Порядок *Paul* → *voit* → *Marie* сигналізує типову схему підмет + присудок + прямий додаток.

В українській:

> *Павло бачить Марію.*  
> *Марію бачить Павло.*

Відмінкові форми зберігають ролі, хоча змінюється інформаційна організація.

## Інформаційна структура

Французька також має способи тематизації та дислокації:

> *Marie, je la vois souvent.*

Тому не слід описувати французьку як мову абсолютно фіксованого порядку. Йдеться про різну граматичну «вартість» перестановки.

**Типова помилка:** переносити українську перестановку *об'єкт + дієслово + підмет* у нейтральне французьке речення без спеціальної конструкції.
