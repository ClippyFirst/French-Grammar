# Позиція об'єктних займенників

У простому реченні **me, te, le, la, les, lui, leur, y, en** розташовуються перед дієсловом.\n\n> **Je le vois.**\n> **Nous lui parlons.**\n> **Elle en achète.**\n\nЦе відрізняє їх від повних іменних додатків, які зазвичай стоять після дієслова.\n\n## Два займенники\n\nЗа наявності кількох клитиків порядок не довільний: **Je le lui donne.** Тут **le** передає COD, а **lui** — COI.\n\nТипова послідовність перед дієсловом охоплює окремі позиції для me/te/se/nous/vous, le/la/les, lui/leur, y та en. Їх не можна переставляти довільно.\n\n## Складені часи\n\nУ **passé composé** займенник стоїть перед допоміжним дієсловом: **Je l'ai vu.**\n\n> **Elle lui a parlé.**\n\nЗайменник не переноситься перед participe passé.\n\n## Інфінітив\n\nЯкщо займенник є доповненням інфінітива, він зазвичай стоїть безпосередньо перед інфінітивом: **Je vais le voir.**\n\nЦе відрізняється від випадку, коли займенник належить особовому дієслову: **Je le veux voir** має іншу, обмеженішу модель; у стандартній сучасній мові часто вживають **Je veux le voir.**\n\n## Наказовий спосіб\n\nСтверджувальний impératif має постпозитивні займенники: **Donne-le-moi !** Заперечний наказовий спосіб повертає їх перед дієсловом: **Ne me le donne pas !**\n\n## Для україномовного учня\n\nНе перекладайте позицію французьких клитиків буквально з української. Вивчайте їх як окрему систему позицій, особливо для комбінацій **le lui**, **la leur**, **y**, **en** та для impératif.
