# 🌟 Дієслово AVOIR (мати) у французькій мові

## 📌 Швидко
> ⏳ **AVOIR** — це **неправильне дієслово**, яке означає "мати" у французькій мові. Вживається для:
> - **Володіння**: J'ai une voiture (У мене є машина)
> - **Вік**: J'ai 25 ans (Мені 25 років)
> - **Дії**: J'ai mangé (Я поїв)
> - **Допоміжне дієслово** у passè composé з більшістю дієслів

> 💡 **Головне**: AVOIR — це **допоміжне дієслово** для більшості дієслів у passè composé!

---

## 📐 Формула

### Теперішній час (Présent)
| Особа | Форма | Переклад |
|-------|-------|----------|
| je | ai | я маю |
| tu | as | ти маєш |
| il/elle/on | a | він/вона має |
| nous | avons | ми маємо |
| vous | avez | ви маєте |
| ils/elles | ont | вони мають |

---

## 🏗️ Утворення

### ✅ Теперішній час (Présent)
```
ai, as, a, avons, avez, ont
```

### ✅ Минулий складений час (Passé composé)
**AVOIR + дієприкметник минулого часу (participe passé)**
```
j'ai eu, tu as eu, il a eu, nous avons eu, vous avez eu, ils ont eu
```

### ✅ Минулий недоконаний час (Imparfait)
```
j'avais, tu avais, il avait, nous avions, vous aviez, ils avaient
```

### ✅ Майбутній простий час (Futur simple)
```
jaurai, auras, aura, aurons, aurez, auront
```

### ✅ Умовний теперішній час (Conditionnel présent)
```
j'aurais, tu aurais, il aurait, nous aurions, vous auriez, ils auraient
```

### ✅ Наказовий спосіб (Impératif)
```
aie, ayons, ayez
```

## 🎯 Вживання

### 1. 📦 Володіння
**AVOIR + іменник** = "мати"

| Конструкція | Приклад | Переклад |
|-------------|---------|----------|
| **AVOIR + предмет** | J'ai une voiture. | У мене є машина. |
| **AVOIR + тварина** | Il a un chat. | У нього є кіт. |
| **AVOIR + людина** | Nous avons des amis. | У нас є друзі. |
| **AVOIR + гроші** | J'ai 100 euros. | У мене є 100 євро. |

**Приклади:**
- J'**ai** un livre intéressant. (У мене цікава книга.)
- Tu **as** une belle maison. (У тебе красивий будинок.)
- Il **a** une sœur. (У нього є сестра.)
- Nous **avons** deux enfants. (У нас двоє дітей.)

> ⚠️ **УВАГА**: У французькій мові **не вживається артикль** перед професією з AVOIR!
> ❌ J'ai un médecin. → ✅ Je suis médecin.

---

### 2. 🎂 Вік
**AVOIR + вік + ans** = "мені X років"

| Вік | Приклад | Переклад |
|------|---------|----------|
| **1 рік** | J'ai 1 an. | Мені 1 рік. |
| **21 рік** | J'ai 21 ans. | Мені 21 рік. |
| **25 років** | J'ai 25 ans. | Мені 25 років. |
| **30 років** | J'ai 30 ans. | Мені 30 років. |

**Приклади:**
- J'**ai** 20 ans. (Мені 20 років.)
- Tu **as** quel âge? (Скільки тобі років?)
- Il **a** 45 ans. (Йому 45 років.)
- Nous **avons** le même âge. (Нам один вік.)

> ⚠️ **УВАГА**: У французькій мові **вживається AVOIR**, а не ÊTRE для віку!
> ❌ Je suis 25 ans. → ✅ J'ai 25 ans.

---

### 3. 🍽️ Дії (з дієприкметниками)
**AVOIR + дієприкметник** = закінчена дія

| Дія | Приклад | Переклад |
|------|---------|----------|
| **Їсти** | J'ai mangé. | Я поїв. |
| **Пити** | J'ai bu. | Я випив. |
| **Зробити** | J'ai fait. | Я зробив. |
| **Побачити** | J'ai vu. | Я побачив. |
| **Чути** | J'ai entendu. | Я почув. |

**Приклади:**
- J'**ai** déjà mangé. (Я вже поїв.)
- Il **a** fini ses devoirs. (Він закінчив домашнє завдання.)
- Nous **avons** visité Paris. (Ми відвідали Париж.)
- Elles **ont** regardé un film. (Вони подивилися фільм.)

---

### 4. ❤️ Відчуття та емоції
**AVOIR + відчуття** = "відчувати"

| Відчуття | Приклад | Переклад |
|----------|---------|----------|
| **Avoir faim** | J'ai faim. | Я голодний. |
| **Avoir soif** | J'ai soif. | Я спраглий. |
| **Avoir sommeil** | J'ai sommeil. | Мені хочеться спати. |
| **Avoir peur** | J'ai peur. | Я боюся. |
| **Avoir chaud** | J'ai chaud. | Мені жарко. |
| **Avoir froid** | J'ai froid. | Мені холодно. |
| **Avoir raison** | J'ai raison. | Я правий. |
| **Avoir tort** | J'ai tort. | Я не правий. |
| **Avoir besoin de** | J'ai besoin d'aide. | Мені потрібна допомога. |
| **Avoir envie de** | J'ai envie de dormir. | Мені хочеться спати. |

**Приклади:**
- J'**ai** faim, je veux manger. (Я голодний, хочу їсти.)
- Il **a** peur du noir. (Він боїться темряви.)
- Nous **avons** besoin de repos. (Нам потрібен відпочинок.)
- Elles **ont** envie de voyager. (Вони хочуть подорожувати.)

### 6. 🔄 Допоміжне дієслово у Passé composé
**AVOIR** використовується як допоміжне дієслово для більшості дієслів у passè composé:

| Дієслово | Passé composé | Переклад |
|----------|---------------|----------|
| **manger** | J'ai mangé | Я поїв |
| **boire** | J'ai bu | Я випив |
| **finir** | J'ai fini | Я закінчив |
| **vendre** | J'ai vendu | Я продав |
| **attendre** | J'ai attendu | Я чекав |

> 💡 **DR & MR VANDERTRAMP** використовують **ÊTRE**, а не AVOIR у passè composé!

## 🔄 Порівняння: AVOIR vs ÊTRE

| Дієслово | Вживання | Приклад |
|-----------|----------|---------|
| **AVOIR** | Володіння | J'ai une voiture |
| **AVOIR** | Вік | J'ai 25 ans |
| **AVOIR** | Дії (з дієприкметниками) | J'ai mangé |
| **AVOIR** | Відчуття | J'ai faim |
| **ÊTRE** | Представлення | Je suis Marie |
| **ÊTRE** | Опис | Il est grand |
| **ÊTRE** | Професія | Je suis médecin |
| **ÊTRE** | Місце | Il est à Paris |
| **ÊTRE** | Час | Il est 8h |
| **ÊTRE** | Стан | Je suis fatigué |
| **ÊTRE** | Допоміжне (DR & MR VANDERTRAMP) | Il est parti |

## ❌ Поширені помилки українськомовних

### 1. Вік з ÊTRE замість AVOIR
```
❌ Je suis 25 ans. → ✅ J'ai 25 ans.
❌ Il est 30 ans. → ✅ Il a 30 ans.
```
> 💡 **Правило**: Для віку **вживайте AVOIR**, а не ÊTRE!

---

### 2. Артикль перед професією з AVOIR
```
❌ J'ai un médecin. → ✅ Je suis médecin.
❌ Il a un professeur. → ✅ Il est professeur.
```
> 💡 **Правило**: Для професії **вживайте ÊTRE без артикля**!

---

### 3. Плутанина AVOIR та ÊTRE у Passé composé
```
❌ J'ai allé au cinéma. → ✅ Je suis allé au cinéma. (ALLER - DR VANDERTRAMP)
❌ Je suis mangé une pomme. → ✅ J'ai mangé une pomme.
```
> 💡 **Правило**: **DR & MR VANDERTRAMP** використовують **ÊTRE** у passè composé!

---

### 4. Плутанина з відчуттями
```
❌ Je suis faim. → ✅ J'ai faim.
❌ Il est soif. → ✅ Il a soif.
```
> 💡 **Правило**: Для фізичних відчуттів (голод, спрага тощо) **вживайте AVOIR**!

---

### 5. Неправильний порядок у питаннях
```
❌ As-tu une voiture? → ✅ As-tu une voiture? ✅
❌ A-t-il faim? → ✅ A-t-il faim? ✅
```
> 💡 **Правило**: У питаннях **вживайте інверсію**: As-tu? A-t-il? Avons-nous?

## 🇺🇦 Для українськомовних

### 🔥 Основні відмінності від української:

1. **Вік**: У французькій мові **AVOIR**, у українській — "мені X років"
   - 🇫🇷 J'ai 25 ans. = 🇺🇦 Мені 25 років.

2. **Володіння**: У французькій мові **AVOIR**, у українській — "у мене є"
   - 🇫🇷 J'ai une voiture. = 🇺🇦 У мене є машина.

3. **Відчуття**: Багато відчуттів у французькій мові виражаються через **AVOIR**
   - 🇫🇷 J'ai faim. = 🇺🇦 Я голодний.
   - 🇫🇷 J'ai soif. = 🇺🇦 Я спраглий.

4. **Допоміжне дієслово**: У французькій мові **AVOIR** для більшості дієслів у passè composé
   - 🇫🇷 J'ai mangé. = 🇺🇦 Я поїв.

### ⚠️ Типові помилки через вплив української:

1. **Плутанина з "мати" та "бути"**:
   - ❌ Je suis une voiture. → ✅ J'ai une voiture.

2. **Вік з ÊTRE**:
   - ❌ Je suis 30 ans. → ✅ J'ai 30 ans.

3. **Артикль перед професією**:
   - ❌ J'ai un médecin. → ✅ Je suis médecin.
