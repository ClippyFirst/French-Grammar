# Модальність можливості

## Швидка відповідь

Можливість виражається через *pouvoir*, модальні прислівники, конструкції й контекст.

## 1. Основний засіб: pouvoir

**pouvoir + infinitif** виражає можливість, здатність або дозвіл:

*Je peux venir demain.* — Я можу прийти завтра.

*Elle peut parler français.* — Вона може говорити французькою / уміє говорити французькою.

Контекст визначає, чи це фізична/практична можливість, здатність чи дозвіл.

## 2. Ймовірна можливість

Можливість як припущення часто виражається:

*Il peut être chez lui.* — Можливо, він удома.

*Cela peut arriver.* — Таке може трапитися.

Тут *pouvoir* не означає дозвіл.

## 3. Інші засоби

- *il est possible que + subjonctif*;
- *peut-être*;
- *éventuellement*;
- *avoir la possibilité de*.

*Il est possible qu'elle soit déjà partie.* — Можливо, вона вже пішла.

## 4. Необхідно відрізняти

*Tu peux partir.* може означати «ти можеш піти» у значенні дозволу або можливості.

*Tu dois partir.* — Ти мусиш піти.

*Il est possible que...* — можливо, що...

Отже, модальне значення визначає не лише одне слово.

## Підсумок

Для можливості базовою конструкцією є **pouvoir + infinitif**, але точний тип можливості визначається контекстом.

## Практичний алгоритм

1. Визнач модальне значення: можливість, необхідність, бажання, припущення, обов'язок або дозвіл.
2. Встанови носія модальності.
3. Вибери особову, безособову або лексичну конструкцію.
4. Перевір часову перспективу та контекст.
5. Не перекладай модальне дієслово одним українським словом без перевірки значення.

## Пов'язані теми

Пов'язано з *conditionnel*, *subjonctif*, інфінітивними конструкціями, непрямою мовою та часовою перспективою.
