# Непрямий наказ і прохання

## Швидка відповідь

Наказ або прохання у французькій не передається однією універсальною конструкцією. Вибір залежить від дієслова введення та того, чи збігається виконавець дії з адресатом.

Найтиповіша модель:

§§MDEMPH0§§

§§MDEMPH0§§ — Він просить його / її прийти.

Для наказу:

§§MDEMPH0§§ — Викладач каже йому / їй зачинити двері.

## 1. Спільний виконавець

Якщо дія наказу виконується адресатом:

§§MDEMPH0§§

→ §§MDEMPH0§§

§§MDEMPH0§§

→ §§MDEMPH0§§

У другому прикладі §§MDEMPH0§§ у прямій мові стає §§MDEMPH1§§ у непрямій конструкції, бо змінилася перспектива.

## 2. Que + subjonctif

Коли конструкція має окремий підмет і модель керування цього вимагає, можливе §§MDEMPH0§§:

§§MDEMPH0§§

Це не просто механічна заміна імператива. §§MDEMPH0§§ є окремою моделлю керування.

Порівняйте:

§§MDEMPH0§§ — просить Марі прийти.

§§MDEMPH0§§ — просить, щоб Марі прийшла.

## 3. Dire de та dire que

§§MDEMPH0§§ — Він каже йому / їй піти.

§§MDEMPH0§§ — Він каже, що піде.

Ці моделі не взаємозамінні: перша передає директиву, друга — твердження.

## 4. Займенники

§§MDEMPH0§§

→ §§MDEMPH0§§

Зміна §§MDEMPH0§§ пов'язана з тим, хто є мовцем і ким є адресат у новій синтаксичній рамці.

## 5. Негативний наказ

§§MDEMPH0§§

→ §§MDEMPH0§§

Заперечення переходить до інфінітивної конструкції:

§§MDEMPH0§§

## Типові помилки

- §§MDEMPH0§§ — змішано дві моделі;
- §§MDEMPH0§§ — можливі діалектні/контекстні варіанти слід не переносити як базову модель; для нейтрального стандарту вибирайте модель відповідно до керування;
- збереження §§MDEMPH0§§ після §§MDEMPH1§§;
- неправильна заміна займенника.

## Алгоритм

1. Визначте, це твердження чи директива.
2. Визначте виконавця дії.
3. Перевірте модель дієслова: §§MDEMPH0§§, §§MDEMPH1§§, §§MDEMPH2§§ тощо.
4. Перебудуйте займенники.
5. Для заперечення використайте §§MDEMPH0§§.
