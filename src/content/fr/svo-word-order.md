# SVO у французькій мові

Модель **SVO (Subject–Verb–Object)** добре описує багато простих французьких речень.\n\n> **Paul mange une pomme.**\n> **Nous regardons le film.**\n> **Marie connaît cette ville.**\n\nТут **Paul / Nous / Marie** — підмети, **mange / regardons / connaît** — присудки, а **une pomme / le film / cette ville** — прямі додатки.\n\n## Чому SVO важлива\n\nФранцузька значною мірою використовує лінійну позицію для вираження синтаксичних відношень. Особливо це помітно у конструкціях із двома іменними групами: перестановка може змінити роль компонента або зробити речення неприродним.\n\n> **Le chien poursuit le chat.**\n\nУ нейтральному варіанті перша іменна група є суб'єктом, друга — об'єктом. Для зміни інформаційної структури французька частіше використовує спеціальні конструкції, ніж довільну перестановку.\n\n## Коли схема SVO розширюється\n\nПісля об'єкта можуть стояти обставини: **Marie lit le livre dans le train.** Перед дієсловом можуть з'являтися клитичні займенники: **Je le vois.** Тоді поверхнева послідовність уже не виглядає як просте S–V–O, хоча базова синтаксична структура зберігається.\n\nПасив також змінює поверхневий порядок: **Le chat est poursuivi par le chien.** Колишній об'єкт стає граматичним підметом пасивної конструкції.\n\n## Для україномовного учня\n\nSVO — це модель нейтрального речення, а не правило для кожного речення. Її корисно використовувати як відправну точку, після чого окремо вивчати позицію займенників, прислівників, обставин і конструкції інформаційного виділення.
