# SVO у французькій мові

Модель §§MDEMPH0§§ добре описує багато простих французьких речень.\n\n> §§MDEMPH1§§\n> §§MDEMPH2§§\n> §§MDEMPH3§§\n\nТут §§MDEMPH4§§ — підмети, §§MDEMPH5§§ — присудки, а §§MDEMPH6§§ — прямі додатки.\n\n## Чому SVO важлива\n\nФранцузька значною мірою використовує лінійну позицію для вираження синтаксичних відношень. Особливо це помітно у конструкціях із двома іменними групами: перестановка може змінити роль компонента або зробити речення неприродним.\n\n> §§MDEMPH7§§\n\nУ нейтральному варіанті перша іменна група є суб'єктом, друга — об'єктом. Для зміни інформаційної структури французька частіше використовує спеціальні конструкції, ніж довільну перестановку.\n\n## Коли схема SVO розширюється\n\nПісля об'єкта можуть стояти обставини: §§MDEMPH8§§ Перед дієсловом можуть з'являтися клитичні займенники: §§MDEMPH9§§ Тоді поверхнева послідовність уже не виглядає як просте S–V–O, хоча базова синтаксична структура зберігається.\n\nПасив також змінює поверхневий порядок: §§MDEMPH10§§ Колишній об'єкт стає граматичним підметом пасивної конструкції.\n\n## Для україномовного учня\n\nSVO — це модель нейтрального речення, а не правило для кожного речення. Її корисно використовувати як відправну точку, після чого окремо вивчати позицію займенників, прислівників, обставин і конструкції інформаційного виділення.
