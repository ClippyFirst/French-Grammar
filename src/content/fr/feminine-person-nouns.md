# Жіночі форми назв осіб

Французька активно використовує **гендерно марковані назви осіб**, і для багатьох професій, посад та занять існують окремі жіночі форми. Їх потрібно відрізняти від механічного додавання закінчення: французька має кілька історично сформованих моделей, а деякі назви допускають паралельні варіанти.

## Базовий принцип

Часто жіноча форма утворюється від чоловічої:

| Чоловіча | Жіноча |
|---|---|
| *un étudiant* | *une étudiante* |
| *un candidat* | *une candidate* |
| *un président* | *une présidente* |
| *un directeur* | *une directrice* |
| *un acteur* | *une actrice* |

Зміна форми іменника супроводжується узгодженням визначників та прикметників:

> *Un jeune directeur est arrivé.*  
> *Une jeune directrice est arrivée.*

## Не всі моделі однакові

У частині слів змінюється суфікс, у частині — закінчення або орфографічна форма. Наприклад, *serveur → serveuse*, *vendeur → vendeuse*, *musicien → musicienne*. Тому продуктивне правило має бути лексично конкретним.

Окремі назви мають однакову форму для двох родів:

> *un journaliste* / *une journaliste*  
> *un ministre* / *une ministre*

У таких випадках рід визначається визначником та узгодженням.

## Посади й сучасна норма

У сучасній французькій жіночі назви професій і посад широко використовуються. Конкретна форма може залежати від країни, інституції та мовної політики. Тому словник або офіційний стиль конкретної організації може бути важливим джерелом для окремої назви.

**Типова помилка:** утворювати жіночу форму за однією універсальною схемою.

**Алгоритм:** визначити чоловічу форму → перевірити словникову модель → утворити жіночу форму → узгодити визначники й прикметники.
