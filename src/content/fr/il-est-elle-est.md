# Il est / elle est

**Il est** та **elle est** — стандартні поєднання особового займенника з **être**.\n\n> **Il est médecin.**\n> **Elle est française.**\n> **Elle est à Paris.**\n\nЇх не слід механічно замінювати на **c'est**. Обидві конструкції можуть бути близькими за змістом, але мають різну синтаксичну організацію.\n\n## Професія, національність, характеристика\n\nПісля **il/elle est** прикметник без артикля є типовим: **Elle est intelligente.** Так само можливі деякі іменні предикативи без артикля, особливо назви професії або ролі: **Il est médecin.**\n\nПорівняйте з іменною групою з детермінативом: **C'est un médecin.**\n\n## Місце та стан\n\n**Il est à Paris**, **elle est au bureau**, **il est prêt** — звичайні предикативні конструкції. У них особовий займенник прямо є граматичним підметом.\n\n## Il est vs c'est\n\nУ **Il est intéressant** займенник **il** може посилатися на конкретний референт або на ситуацію залежно від контексту. У **C'est intéressant** **ce** часто представляє ситуацію, факт або попереднє висловлення.\n\n> **Paul est intelligent. Il est très calme.**\n> **Paul a refusé. C'est surprenant.**\n\n## Для україномовного учня\n\nКорисна практична відмінність: **il/elle est + adjectif** — звичайна предикація про суб'єкта; **c'est + groupe nominal/adjectif** — часто presentative або коментувальна конструкція. У деталях вибір залежить від структури та контексту.
