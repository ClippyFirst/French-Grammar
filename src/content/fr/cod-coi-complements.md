# Граматичні функції COD, COI та complément

У французькому реченні §§MDEMPH0§§ (§§MDEMPH2§§) — прямий додаток, §§MDEMPH1§§ (§§MDEMPH3§§) — непрямий додаток, а слово §§MDEMPH4§§ є ширшим поняттям для залежного компонента.

## Швидка відповідь

> §§MDEMPH0§§ → §§MDEMPH1§§ = COD.  
> §§MDEMPH0§§ → §§MDEMPH1§§ = COI.

Головна діагностика — не український відмінок, а французька синтаксична структура та керування дієслова.

## 1. COD

COD безпосередньо залежить від дієслова без прийменника:

> §§MDEMPH0§§

Відновлення: §§MDEMPH0§§ → §§MDEMPH1§§.

COD може бути займенником:

> §§MDEMPH0§§

## 2. COI

COI вводиться прийменником, який керується конструкцією:

> §§MDEMPH0§§

Не кожна група після прийменника є COI. Прийменник може вводити інший тип комплемента.

## 3. Complément як ширше поняття

§§MDEMPH0§§ може позначати різні залежні компоненти:

> §§MDEMPH0§§

§§MDEMPH0§§ не треба автоматично називати COI лише через наявність §§MDEMPH1§§: це обставинний/локативний компонент.

## 4. Український контраст

Українські відмінки часто дозволяють швидко розрізнити додатки, але французька значно сильніше спирається на порядок слів, прийменникове керування та тип дієслова.

## Типова помилка

❌ «Є прийменник → це COI».

✓ Спочатку визнач функцію компонента в конкретній конструкції.

## Алгоритм

1. Знайди дієслово.
2. Визнач його модель керування.
3. Перевір наявність прийменника.
4. Визнач синтаксичну функцію.
5. Не перекладай французьку функцію механічно через український відмінок.

## Мінітест

§§MDEMPH0§§ → COD.

§§MDEMPH0§§ → COI.

§§MDEMPH0§§ → §§MDEMPH1§§ — не автоматично COI; це локативний/напрямковий компонент.
