## Швидка відповідь

Регіональна синтаксична варіантність означає, що певна синтаксична модель має відмінне географічне поширення, частотність або реалізацію.

Щоб назвати конструкцію регіональною, недостатньо того, що вона рідко зустрічається у вашому підручнику. Потрібні дані про її територію та функцію.

## 1. Що може варіювати

Регіональна синтаксична відмінність може стосуватися:

- порядку компонентів;
- займенникової структури;
- прийменникового керування;
- способу побудови питання;
- дискурсивних конструкцій;
- частотності певної підрядної моделі.

Але кожен випадок треба описувати окремо.

## 2. Регіональність ≠ незвичність

Порівняйте:

*Je pense qu'il viendra demain.*

*Nous avons terminé le travail.*

Ці конструкції мають широке французьке поширення. Якщо мовець використовує незвичний для учня варіант, спочатку треба перевірити, чи він:

1. загальнофранцузький;
2. усно-розмовний;
3. регіональний;
4. соціально маркований;
5. нестандартний.

## 3. Роль валентності

Багато «регіональних» синтаксичних підозр насправді є питаннями керування.

Наприклад, незвичний прийменник після дієслова не слід класифікувати як регіоналізм, поки не встановлено модель дієслова та її географічне поширення.

Тому:

**дієслово → валентність → функція → регіон → регістр.**

## 4. Регістр

Одна конструкція може бути:

- нейтральною в усному мовленні;
- неформальною;
- формальною;
- літературною;
- регіональною.

Ці характеристики можуть перетинатися.

## 5. Український контраст

Українська допускає інший набір порядків слів і сильніше маркує частину синтаксичних відношень відмінками. Через це французька конструкція може здаватися «дивною» просто тому, що вона не відповідає українській моделі.

Це ще не доказ регіональності.

## 6. Практичний алгоритм

Для почутої або прочитаної конструкції:

**розбір структури → функція → базова стандартна модель → реальний корпусний/довідковий статус → географія → регістр.**

Якщо географічний параметр не встановлено, позначте явище як «варіантність» або «незвичне для джерела», а не як регіоналізм.

## 7. Типові помилки

«Не так у підручнику → регіональне» — хибно.

«Регіональне → неправильне» — хибно.

«Усне → регіональне» — хибно.

«Одна конструкція → характеристика всього регіону» — надмірне узагальнення.
