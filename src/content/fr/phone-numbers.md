# Телефонні номери

## Швидка відповідь

Телефонний номер — §§MDEMPH0§§, а не кількісне число. Тому: §§MDEMPH1§§, але §§MDEMPH2§§. У Франції внутрішній формат зазвичай має десять цифр і часто записується парами: §§MDEMPH3§§. Міжнародний формат цього номера: §§MDEMPH4§§.

## 1. Numéro чи nombre?

- §§MDEMPH0§§ — число/кількість;
- §§MDEMPH0§§ — номер, ідентифікатор.

Порівняй:

- §§MDEMPH0§§ — кількість людей;
- §§MDEMPH0§§ — номер телефону;
- §§MDEMPH0§§ — кількість сторінок;
- §§MDEMPH0§§ — номер сторінки.

## 2. Як запитати номер

- §§MDEMPH0§§
- §§MDEMPH0§§
- §§MDEMPH0§§
- §§MDEMPH0§§

У контексті §§MDEMPH0§§ може вживатися без §§MDEMPH1§§.

## 3. Французький внутрішній формат

Приклад:

§§MDEMPH0§§

Для мобільного:

§§MDEMPH0§§  
§§MDEMPH0§§

Групування допомагає диктувати та записувати номер. Це не одне велике число.

## 4. Міжнародний формат

Код Франції — §§MDEMPH0§§. Початковий внутрішній §§MDEMPH1§§ після коду не повторюється:

§§MDEMPH0§§ → §§MDEMPH1§§.

Це правило формату національного номера, а не правило французької граматики. Для інших країн структура може бути іншою.

## 5. Читання

Цифри можуть називатися послідовно або групами. Практичне правило — зберігати межі груп, щоб слухач міг правильно записати номер.

Не перетворюй:

§§MDEMPH0§§

на одне кількісне число. Телефонний номер має функцію ідентифікатора.

## 6. Інші ідентифікатори

Та сама опозиція працює в:

- §§MDEMPH0§§ — номер справи;
- §§MDEMPH0§§ — серійний номер;
- §§MDEMPH0§§ — номер сторінки.

Порівняй §§MDEMPH0§§ та §§MDEMPH1§§: номер сторінки ≠ кількість сторінок.

## 7. Український контраст

«Номер телефону» → §§MDEMPH0§§.

«Кількість телефонів» → §§MDEMPH0§§.

«Номер сторінки» → §§MDEMPH0§§.

«Кількість сторінок» → §§MDEMPH0§§.

Тобто вибір слова залежить від функції, а не від самої цифри.

## Типові помилки

❌ §§MDEMPH0§§ → ✅ §§MDEMPH1§§  
❌ читати номер як одне величезне число → ✅ читати цифрами/групами  
❌ §§MDEMPH0§§ для стандартного міжнародного запису → ✅ §§MDEMPH1§§  
❌ §§MDEMPH0§§ → ✅ §§MDEMPH1§§

## Практичний алгоритм

1. Визнач: кількість чи ідентифікатор.
2. Для номера використай §§MDEMPH0§§.
3. Перевір національний формат.
4. Для міжнародного запису перевір код і національний префікс.
5. Під час диктування зберігай групування.
6. Не змішуй телекомунікаційний формат із граматикою.

## Мінітест

1. §§MDEMPH0§§.
2. §§MDEMPH0§§ = кількість.
3. §§MDEMPH0§§ = номер.
4. §§MDEMPH0§§.

§§MDEMPH0§§ §§MDEMPH1§§.
