# Телефонні номери

## Швидка відповідь

Телефонний номер — **ідентифікатор**, а не кількісне число. Тому: *un numéro de téléphone*, але *le nombre de téléphones*. У Франції внутрішній формат зазвичай має десять цифр і часто записується парами: *01 23 45 67 89*. Міжнародний формат цього номера: *+33 1 23 45 67 89*.

## 1. Numéro чи nombre?

- *un nombre* — число/кількість;
- *un numéro* — номер, ідентифікатор.

Порівняй:

- *le nombre de personnes* — кількість людей;
- *le numéro de téléphone* — номер телефону;
- *le nombre de pages* — кількість сторінок;
- *le numéro de page* — номер сторінки.

## 2. Як запитати номер

- *Quel est votre numéro de téléphone ?*
- *Quel est ton numéro ?*
- *Voici mon numéro.*
- *Pouvez-vous répéter votre numéro ?*

У контексті *numéro* може вживатися без *de téléphone*.

## 3. Французький внутрішній формат

Приклад:

*01 23 45 67 89*

Для мобільного:

*06 12 34 56 78*  
*07 12 34 56 78*

Групування допомагає диктувати та записувати номер. Це не одне велике число.

## 4. Міжнародний формат

Код Франції — *+33*. Початковий внутрішній *0* після коду не повторюється:

*01 23 45 67 89* → *+33 1 23 45 67 89*.

Це правило формату національного номера, а не правило французької граматики. Для інших країн структура може бути іншою.

## 5. Читання

Цифри можуть називатися послідовно або групами. Практичне правило — зберігати межі груп, щоб слухач міг правильно записати номер.

Не перетворюй:

*01 23 45 67 89*

на одне кількісне число. Телефонний номер має функцію ідентифікатора.

## 6. Інші ідентифікатори

Та сама опозиція працює в:

- *numéro de dossier* — номер справи;
- *numéro de série* — серійний номер;
- *numéro de page* — номер сторінки.

Порівняй *page 25* та *vingt-cinq pages*: номер сторінки ≠ кількість сторінок.

## 7. Український контраст

«Номер телефону» → *numéro de téléphone*.

«Кількість телефонів» → *nombre de téléphones*.

«Номер сторінки» → *numéro de page*.

«Кількість сторінок» → *nombre de pages*.

Тобто вибір слова залежить від функції, а не від самої цифри.

## Типові помилки

❌ *nombre de téléphone* → ✅ *numéro de téléphone*  
❌ читати номер як одне величезне число → ✅ читати цифрами/групами  
❌ *+33 01 23 45 67 89* для стандартного міжнародного запису → ✅ *+33 1 23 45 67 89*  
❌ *le nombre de page 25* → ✅ *le numéro de page 25*

## Практичний алгоритм

1. Визнач: кількість чи ідентифікатор.
2. Для номера використай *numéro*.
3. Перевір національний формат.
4. Для міжнародного запису перевір код і національний префікс.
5. Під час диктування зберігай групування.
6. Не змішуй телекомунікаційний формат із граматикою.

## Мінітест

1. *______ de téléphone*.
2. *le ______ de téléphones* = кількість.
3. *le ______ de page* = номер.
4. *+33 ______ 23 45 67 89*.

**Відповіді:** *numéro; nombre; numéro; 1*.
