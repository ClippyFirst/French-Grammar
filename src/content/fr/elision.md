# Élision

## Швидка відповідь

**Élision** — це випадіння кінцевої голосної в певних службових словах перед наступним словом, яке починається з **голосного звука або h muet**. На письмі випадіння позначається **апострофом**.

- **je aime** → **j'aime**
- **le ami** → **l'ami**
- **de Antoine** → **d'Antoine**
- **que il** → **qu'il**

Елізія — це не загальне правило «будь-яке слово на голосну скорочується». Вона стосується визначених слів і конструкцій.

## Основні випадки

Найважливіші слова з регулярною елізією:

| Повна форма | Перед голосним / h muet | Приклад |
|---|---|---|
| **je** | **j'** | **j'arrive** |
| **le / la** | **l'** | **l'homme, l'école** |
| **de** | **d'** | **d'accord, d'Anne** |
| **que** | **qu'** | **qu'il vient** |
| **ne** | **n'** | **n'arrive pas** |
| **me** | **m'** | **m'aider** |
| **te** | **t'** | **t'aimer** |
| **se** | **s'** | **s'arrêter** |
| **ce** | **c'** | **c'est** |
| **si** | **s'** лише перед **il/ils** | **s'il vient, s'ils arrivent** |

Важливо: елізія залежить від конкретного слова. Наприклад, **tu** не перетворюється на *t'* перед голосним: **tu arrives**.

## Голосний звук, а не просто літера

Умова визначається вимовою.

З **h muet**:

- **l'homme**
- **d'habitude**
- **qu'il**

З **h aspiré** елізія блокується:

- **le héros**, не *l'héros*;
- **la honte**, не *l'honte*;
- **le haricot**, не *l'haricot*.

Тому тип початкового **h** має безпосередній орфографічний наслідок.

## Елізія та liaison — не одне й те саме

Порівняйте:

**Élision**
- **le ami** → **l'ami**
- змінюється написання форми.

**Liaison**
- **les amis** → [le.z‿a.mi]
- написання **les** не змінюється; змінюється вимова.

**Enchaînement**
- уже наявний кінцевий приголосний переходить до наступного складу.

Три явища можуть бути пов'язані зі зв'язним мовленням, але механізми різні.

## Апостроф

У сучасній французькій апостроф позначає елізію, а не довільне скорочення.

Нормативні приклади:

- **j'aime**
- **l'arbre**
- **d'Hector**
- **qu'elle**
- **n'est**
- **s'il**

Не пишіть апостроф лише тому, що два слова «незручно стикаються».

## Особові імена

Елізія може відбуватися перед власними назвами:

- **la maison d'Antoine**
- **le travail d'Hélène**
- **qu'Alexandre arrive**

Тобто власна назва не скасовує правило.

У сумнівних випадках з початковим **h** потрібно враховувати конкретну вимову слова та нормативний узус.

## Особливий випадок si

**si** зазвичай не елімінується перед голосним:

- **si elle vient**
- **si on part**

Але перед **il / ils** маємо традиційну елізію:

- **s'il vient**
- **s'ils arrivent**

Не поширюйте цю модель на *si elle*.

## Український контраст

Український апостроф не виконує тієї самої функції: він позначає фонетико-орфографічну властивість межі морфем/звуків, а не систематичне випадіння службової голосної перед наступним словом.

Тому французький апостроф треба вивчати як частину **системи елізії**, а не як «український апостроф іншою мовою».

## Типові помилки

❌ *le héros* → *l'héros*

✅ **le héros** — *h aspiré* блокує елізію.

❌ *si elle vient* → *s'elle vient*

✅ **si elle vient**.

❌ *tu arrives* → *t'arrives*.

✅ **tu arrives**.

❌ *ne parle* → *n'parle* у нормативному письмі.

✅ **ne parle pas**.

## Практична перевірка

1. ___ homme. (**le / l'**)
2. ___ héros. (**le / l'**)
3. ___ arrive. (**je / j'**)
4. ___ elle vient. (**si / s'**)
5. ___ il arrive. (**si / s'**)
6. la maison ___ Antoine. (**de / d'**)

**Відповіді:** 1. **l'**; 2. **le**; 3. **j'**; 4. **si**; 5. **s'**; 6. **d'**.
