# Граматична варіантність у сучасному вжитку

**Граматична варіантність** означає наявність кількох реалізацій, пов'язаних із функцією, значенням, регістром, жанром, регіоном або частотністю.

## Чотири питання

Для будь-якої форми перевіряйте:

1. Чи вона граматично можлива?
2. Де вона вживається?
3. Наскільки вона поширена?
4. Який її статус — стандартний, розмовний, книжний, регіональний тощо?

Наприклад:

*Je ne sais pas.*  
*Je sais pas.*

Друга форма характерна для багатьох усних неформальних контекстів, але не повинна автоматично переноситися в офіційне письмо.

## Варіанти питання

*Tu viens ?*  
*Est-ce que tu viens ?*  
*Viens-tu ?*

Функція може бути близькою, але структурне та стилістичне оформлення різниться.

## Частотність ≠ норма

Часта форма може бути стилістично маркованою, а рідкісна — стандартною. Так само регіональний стандарт не слід змішувати з загальнофранцузькою нормою.

## Українсько-французький контраст

Внутрішньофранцузька варіантність і міжмовна інтерференція — різні явища. Відмінність від української моделі сама по собі не доводить помилки, як і відмінність від підручникового прикладу не доводить нормативності.

## Практична матриця

**форма → функція → контекст → регістр → регіон → частотність → статус.**

**Типові помилки:** використовувати найчастішу почуту форму всюди; вважати все поза підручником помилкою; плутати регіональну й нестандартну форму.

**Алгоритм:** ідентифікуйте форму → встановіть функцію → перевірте контекст → визначте регістр/регіон → оцініть доречність.
